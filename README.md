# ojhel
Interactive CLI to generate project-specific `.gitignore` files with zero configuration.

## Features
-  **5 Project Types**: Vite React, Next.js, Express, Fastify, Vanilla JS
-  **Language Support**: TypeScript and JavaScript
-  **Interactive Prompts**: Simple, guided setup
-  **Smart File Handling**: Append to or override existing `.gitignore`
-  **Next.js Support**: Automatically creates `next-env.d.ts`
-  **Zero Config**: Works out of the box

## Installation & Usage
### Quick Start (Recommended)

```bash
# We Can use a npx/bunx 
pnx ojhel
```
